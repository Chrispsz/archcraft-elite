4. `BARS_EXITS=32` / `BARS_RESTARTS=34` em ~poucos segundos = loop fechado, barra **nunca** fica de pé de forma estável.
5. O gate cobra `BARS_EXITS -eq 0` → `✖`.

⚠️ **Não é OOM/race** (o gate lista "crash/race/OOM" como hipóteses genéricas): `MEM=3383/6920MB` está folgado e o erro é **determinístico por CSS**. O `[error] ... is not a valid property name` descarta race.
