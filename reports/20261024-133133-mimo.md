```
BARS| sh: line 1: /usr/local/bin/craft-pin-status: Permission denied
BARS| sh: line 1: /usr/local/bin/craft-pin-status: Permission denied
```

**Análise:**

- "Permission denied" (não "No such file or directory") → o arquivo **existe** mas não tem permissão de execução (0644) ou tem shebang CRLF.
- 12 ocorrências = ~cada 5s no refresh do waybar → o módulo de pin status está permanentemente quebrado na UI.
- O gate `[9b]` checa `code=203/EXEC|Unable to locate executable` — **não cobre "Permission denied"**. O binário passa pelo gate mas não funciona.
- `BARS_RESTARTS=2` → o bars script reiniciou 2 vezes. Possivelmente uma delas foi causada pela falha do pin-status (ou pode ser comportamento normal de setup). `BARS_EXITS=0` confirma que não houve crash.
- **O gate `waybar sem NENHUMA morte` passa porque "Permission denied" não mata o processo waybar** — o module exec-if retorna exit ≠ 0 e o waybar simplesmente esconde o módulo.

**Impacto no CI:** zero — todos os gates passam.
**Impacto no usuário:** o módulo de pin status na barra waybar está vazio/quebrado.
