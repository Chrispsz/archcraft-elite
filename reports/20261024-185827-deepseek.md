## 4. Correção proposta

### Patch A — escopo do lint por shebang (mínimo e definitivo)

Substituir o corpo do passo (o que o log ecoou em 18:57:19) por:

```yaml
      - name: shellcheck (gate — warning ou acima; infos são intencionais e documentadas)
        run: |
          set -euo pipefail
          shopt -s globstar
          # [lint-scope] v2.0: craft-* deixou de ser "só shell" (craft-dock-gui = Python).
          # Filtrar por shebang: shellcheck só suporta sh/bash/dash/ksh/busybox sh.
          mapfile -t targets < <(
            for f in scripts/*.sh \
                     .ci/*.sh \
                     elite/fragments/*.sh \
                     elite/airootfs/usr/local/bin/elite-tune \
                     elite/airootfs/usr/local/bin/fg-booster \
                     elite/airootfs/usr/local/bin/elite-status \
                     elite/airootfs/usr/local/bin/craft-* \
                     elite/airootfs/etc/skel/.config/labwc/autostart; do
              [[ -f $f ]] || continue
              head -n1 -- "$f" | grep -qE '^#!.*\b(sh|bash|dash|ksh)\b' && printf '%s\n' "$f"
            done | sort -u
          )
          printf 'lint: %d script(s)\n' "${#targets[@]}"
          printf '  %s\n' "${targets[@]}"
          (( ${#targets[@]} > 0 )) || { echo "::error::nenhum script casou o glob — gate cego"; exit 1; }
          shellcheck -S warning -x "${targets[@]}"
```

A asserção de contagem é deliberada: impede que o gate vire "verde" se os caminhos mudarem.
