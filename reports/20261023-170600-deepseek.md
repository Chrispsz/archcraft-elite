## 4. Correção proposta

### 4.1 E2.1 — us PRIMEIRO no mirrorlist do chroot (idempotente; insira logo após o E2)

```bash
# ── E2.1: mirror do chroot — us PRIMEIRO (idempotente) ────────────────
#  Mesma lei do .ci/build.sh → elite_fetch: o cdn77 está cronicamente
#  dessincronizado nos v3. O pacote cachyos-v3-mirrorlist entrega o
#  cdn77 na frente → E3 pega par .db/.db.sig cruzado ("is invalid").
#  Reordena SEM descartar entradas (a live ISO mantém todos os mirrors).
for ml in /etc/pacman.d/cachyos-mirrorlist /etc/pacman.d/cachyos-v3-mirrorlist; do
	[[ -f $ml ]] || continue
	us="$(grep -m1 '^Server = https://us\.cachyos\.org' "$ml" || true)"
	[[ -n $us ]] || us="$(grep -m1 '^Server = ' "$ml" | sed 's|//[^/]*/|//us.cachyos.org/|')"
	[[ -n $us ]] || continue
	tmp="$(mktemp)"
	{ printf '%s\n' "$us"; grep -v '^Server = https://us\.cachyos\.org' "$ml"; } >"$tmp"
	mv "$tmp" "$ml"
	say "E2.1: $(basename "$ml") — us.cachyos.org na frente"
done
```

### 4.2 E3 — sync com auto-cura de skew e **sem mascaramento**

```bash
# ── E3: sync dos dbs do chroot (auto-cura de skew de mirror) ──────────
elite_db_sync() {
	local try log=/tmp/e3-sync.log
	for try in 1 2 3; do
		if pacman -Sy --noconfirm >"$log" 2>&1 && ! grep -q 'is invalid' "$log"; then
			say "E3: dbs sincronizados (tentativa $try)"
			return 0
		fi
		say "E3: sync falhou (tentativa $try) — descartando o par db/db.sig do CachyOS"
		sed -n '1,30p' "$log"
		# SÓ o CachyOS: o [elite-local] é file:// e não deve ser apagado
		rm -f /var/lib/pacman/sync/cachyos*.db /var/lib/pacman/sync/cachyos*.db.sig
		sleep $((try * 15))
	done
	{ # diagnóstico obrigatório — nunca silencioso
		echo "ELITE-FAIL: E3 pacman -Sy não convergiu em 3 tentativas"
		grep -m5 '^Server = ' /etc/pacman.d/cachyos*-mirrorlist || true
		pacman-key --list-keys F3B607488DB35A47 2>&1 | sed -n '1,20p' || true
	} >&2
	return 1
}
elite_db_sync     # SEM '|| true': falha ⇒ set -e aborta o customize ~20 min mais cedo
```

## 5. Riscos do patch

1. **E2.1 muda o mirror que a ISO *shipped* usa.** Mitigado: só **reordena** (us primeiro, todos os demais preservados como fallback). Ainda assim, usuário distante do us perde banda. Alternativa: reordenar só no chroot e restaurar o mirrorlist original antes do squashfs (mais código, mais risco).
2. **`rm -f /var/lib/pacman/sync/*.db` genérico apagaria o `[elite-local]`.** O patch usa `cachyos*.db` deliberadamente — não troque o glob.
3. **E3 passar a abortar** troca “ISO completa + run vermelha” por “run vermelha em 15 min”. É o comportamento desejado (o gate vermelharia do mesmo jeito e o artefato não sobe), mas você perde a ISO de diagnóstico — daí o 4.3.
4. **Retry de 3× com `sleep 15/30/45`** adiciona até ~90 s no pior caso; irrelevante frente aos 78 min do #17.
5. Se a causa real for **chave expirada/rotacionada**, o retry não cura — o run morre mais cedo *e* o dump `pacman-key --list-keys` prova. Não mascare isso relaxando o `SigLevel` do chroot: a conf do chroot vai para a ISO e rebaixaria a verificação das atualizações do usuário.
6. `.pacnew`/uids sem nome (§2.5) **não** é tocado por este patch — precisa de decisão à parte (ordem de `pacstrap`/`airootfs` ou `getent` no verify).
