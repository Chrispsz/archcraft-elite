# Release `elite-system 1.0-103` — A erradicação do Python, a auditoria byte a byte e a consolidação no juiz de casa

A evidência é a **radiografia de linguagens do repo** (62% Shell · 35% Rust ·
1.7% CSS · 0.1% Python): a dose pede a extinção INTEIRA do Python (arquivo
`.py` e heredoc embutido), o enxugamento do Shell e a lente byte a byte no
Rust e no CSS.

## 1 · O juiz de casa `craft-audit` (o Python inteiro vira Rust)

Todo julgamento/parsing de config que vivia em heredoc python migra para o
núcleo std do `craft-tools` (`crates/craft-tools/src/audit.rs`) + o bin CLI
`craft-audit` — **viaja NO pacote** (o rig nunca mais acorda "SEM juiz no
sistema"; o xmllint segue como juiz principal onde existe):

- `xml` — bem-formado de verdade (UM root, tags casadas, nada após o fecho,
  entidade crua é réu);
- `menu` — a gramática E146 (nenhum texto fora de tag, CDATA incluso);
- `ini [--estrito] [--secoes a,b,c]` — a lição E137 + o estrito do fuzzel;
- `yaml` — o gate da v1.1 (Calamares);
- `calamares <raiz>` — o porte INTEGRAL do `validate-calamares.py` (o arquivo
  `.py` é DELETADO; o gate do verify-install.yml o compila no runner);
- `hello <bus.sock>` — o aperto de mão pelo protocolo `elite-core` de verdade;
- `brave-bg <Local State>` — o patch `background_mode.enabled=false`
  idempotente (exit 1/2/3);
- `binds-osd <rc.xml>` — as 5 reescritas EXATAS E74;
- `exec-resolve …` — a resolução executiva de TODO Execute do menu ∪ rc
  (o porte do juízo da fase 40: shlex fiel, `foot -e`, `${TERMINAL:-x}`,
  cadeia `for`, fósseis).

## 2 · O molde PYE50 morre em sh puro (2.500 linhas de heredoc python)

pela expansão de parâmetro do próprio bash (com a ESCAPA de `\` e `&` — o `&`

chegam DECODADOS porque o heredoc do bash não decoda nada):

completo e caso vazio). O PYE57 idem (a poda das `file_permissions` do
profiledef, com strip fiel).
